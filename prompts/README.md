# prompts/ · 迭代记录

这里放每次功能迭代的过程记录。赛项要求「至少 3 个核心功能迭代的完整 Prompt 链」，所以每条都写清楚：当时提了什么要求、AI 给了什么方案、我怎么选、最后怎么验证的。

## 写法约定

- 一次功能迭代一个文件，命名 `NN-功能名.md`，编号跟提交顺序一致；
- 提交信息里带上编号，方便对照；
- 只写真实发生过的事，没做的就写没做；
- token、密钥、手机号一律打码。

## 每条包含

1. **需求**：当时的原话或关键句
2. **上下文**：代码到什么状态、有什么硬限制
3. **拆解**：要交付哪几样，怎么算完成
4. **取舍**：备选方案和放弃的理由（评审最看这段）
5. **接口 / 链路**：改动的具体形状
6. **验证**：跑过什么、结果如何
7. **没做的**：这次没覆盖的部分
