# 演示视频分镜脚本（5–8 分钟 / 1080p）

> 要求：MP4、1080p、5–8 分钟，其中**不少于 2 分钟**的「AI 协同过程复现」。
> 本稿按 6 分 50 秒排，实际录到 5–8 分钟都算合规。

## 录制前准备

| 项 | 要求 |
|---|---|
| 分辨率 | 1920×1080，25 或 30fps，码率 ≥ 8Mbps |
| 声音 | 真人解说，别用软件配音（评委会听出来） |
| 画面 | 浏览器缩放 110%，字号大一点；深色 IDE 主题容易糊，用浅色 |
| 开录前 | `node server/server.js` 先跑起来；后台已登录；浏览器开三个标签：点餐页、后台、GitHub 仓库 |
| 录制工具 | OBS / Windows 自带录屏 / 剪映录屏都行，关键是**分段录**，最后剪 |

## 分段脚本

### 0:00–0:30 片头（30 秒）

- 画面：项目名 + 一句话定位，静态标题页
- 旁白：*"这是给轻食小店做的一套点餐系统。一套后端，两个前端：小程序准备上架，网页版用来演示。核心是两块——商家能改菜单能接单，顾客能按自己的身高体重算出这一餐该吃什么。"*

### 0:30–1:30 痛点与方案（60 秒）

- 画面：讲三个痛点，配点餐页截图（热量累计、售罄置灰）
- 旁白要点：
  1. 轻食客群关心热量，但多数小店只在小程序图里贴一张模糊的营养表；
  2. 估清靠嘴说，线上照样能下单；
  3. 下单后是黑箱，不知道商家看没看到。
- 一句转场：*"所以做了三件事：热量变成菜品一级字段、库存下单即扣、订单状态推到顾客端。"*

### 1:30–3:40 功能演示（2 分 10 秒）★ 主演示

按顺序一镜到底，别剪辑，慢一点：

1. **点餐页**：切类目 → 选一道有规格的菜（牛油果藜麦能量碗）→ 规格弹层选"加大" → 看单价变化 → 加购（飞入动画）→ 购物车角标与热量合计（约 40 秒）
2. **AI 定制**：点顶部入口 → 填女/26/165/58/久坐/减脂 → 生成套餐 → 指读结果："基础代谢 1320、日常消耗 1815、这餐预算 581 千卡；推荐三道一共 590 千卡、蛋白 55 克" → 点"加入购物车"（约 50 秒）
3. **结算下单**：填地址 → 提交 → 跟踪页出现订单号与"等待商家接单"（约 25 秒）
4. **后台接单**：切到 `/admin` → 登录 → 最近订单 → 点"接单" → **切回跟踪页，等 5 秒**，进度条推进到"制作中"、时间轴多一条（约 35 秒）

> 这一步是全片最重要的镜头：**两个窗口并排，让评委亲眼看到状态真的从服务端推过去**。

### 3:40–6:10 AI 协同过程复现（2 分 30 秒）★ 硬性要求

屏幕录制真实的对话过程，不要只放结果：

**片段 A（约 60 秒）：用一段 Prompt 生成核心模块**

- 画面：对话窗口，打出需求（可先粘贴，再逐字展示关键句）
- 展示的 Prompt 大意：*"服务端零第三方依赖，不能引 npm 包。给 /api/recommend 写一个推荐函数：输入性别年龄身高体重活动量目标，算 BMR 和 TDEE，在菜单里搜组合，返回三道菜和偏差。"*
- 画面切到生成的 `recommender.js`，指一下 `Mifflin-St Jeor` 那几行和搜索循环
- 旁白：*"约束先给死——零依赖，它就不会给你搬 Express 或 SQLite 进来。"*

**片段 B（约 60 秒）：一次真实的 Bug 修复**

建议用**建仓时的 400** 或**计划页表单挤行**，两个都有明确的前后对比：

- 展示报错：`{"message":"Problems parsing JSON"}` 与当时的命令
- 展示引导语：*"这条命令在我机器上就是 400，帮我从编码角度排查"*
- 展示定位过程与改法（JSON 写文件，`--data-binary @file`），再跑一次 201
- 旁白：*"报错不要只说'失败了'，把原始响应体贴回去，它才能定位到是 GBK 编码。"*

**片段 C（约 30 秒）：给模型加约束**

- 展示系统提示：*"只改语气，不得修改任何数字"*
- 对比模板文案与润色文案，指出 11 个数字没变
- 旁白：*"大模型只做增强，不参与计算；换坏 Key 会退回模板，接口照常。"*

### 6:10–7:10 可复现性（60 秒）

- 画面：GitHub 仓库首页 → 提交历史（滚一下，27 条）→ `prompts/` 目录 → `snapshots/` 三份纪要 → Actions 绿标
- 旁白：*"提交是按功能拆的，每次提交都能在 prompts 里找到对应的记录。CI 每次 push 都会跑语法检查、小程序类型检查和接口冒烟。"*
- 快剪：新开终端 `node server/server.js` → 浏览器打开 `localhost:3000` → 3 秒内出菜单（证明 10 分钟复现不是口号）

### 7:10–7:40 收尾（30 秒）

- 画面：项目结构树
- 旁白：*"现在小程序端已经能在开发者工具里跑，还没接微信登录和支付；上架要过备案和餐饮类目资质，这些是账号侧的准备工作。代码这块，仓库里都有。"*
- 结束页：仓库地址

## 剪辑与命名

- 导出：`dika-演示视频-1080p.mp4`，H.264；
- 同时传一份到 B 站（设为不公开也可），万一文件损坏有备份；
- 提交时按赛项要求上传视频文件，不要把链接当文件交。
