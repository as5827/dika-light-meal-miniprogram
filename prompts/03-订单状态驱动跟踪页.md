## 1. 需求

> 好的你 1+2 先并行吧

上下文：补第 2 条 Prompt 记录，把「订单状态驱动跟踪页」做成真实闭环——商家在后台点「接单 / 完成」，顾客端跟踪页应当自己变化。

改造前的具体问题（读代码确认）：

| 位置 | 问题 |
|---|---|
| `preview/index.html` 跟踪页 | 进度条 4 个节点是写死的 `class="done"/"current"`，文案「商家已接单 / 预计 12:35 送达」是常量 |
| 时间轴 | 4 条记录时间固定 `12:02 / 12:03 / --:--`，与真实订单无关 |
| 骑手卡片 | 「配送小哥 王师傅 188\*\*\*\*5678」是虚构内容，项目并没有配送体系 |
| 数据 | 订单只有 `status` 与 `updatedAt`，没有状态变更历史，无法还原时间轴 |

## 2. 拆解

- **数据层**：订单增加 `events: [{ status, at }]` 事件链，创建时写入 `pending`，后台每次改状态追加一条；
- **接口层**：新增公开的 `GET /api/orders/:id`（凭订单号查询，手机号脱敏），返回事件链；
- **展示层**：跟踪页按 `status` 映射节点状态、按 `events` 渲染时间轴；进入页面后每 5 秒轮询一次，到终态停止；
- **诚实性**：删掉虚构的骑手卡片与「预计送达时间」——没有的数据不假装有。

## 3. 取舍

| 决策点 | 备选 | 选择与理由 |
|---|---|---|
| 状态推进通知 | 前端轮询 / SSE / WebSocket | **5 秒轮询**。零依赖约束下 SSE 要额外维护长连接与断线重连，WebSocket 在原生 `http` 上要自己实现握手与帧解析；订单状态变化是低频事件，轮询成本可忽略 |
| 轮询终点 | 一直轮询 / 到终态停止 | **`done` / `canceled` 停止**，并在离开跟踪页时清掉定时器，避免后台标签页长期空转 |
| 时间轴数据 | 用 `updatedAt` 推算 / 落事件链 | **落 `events`**。只有一个 `updatedAt` 时，第二次改状态会覆盖第一次的时间，时间轴必然错位 |
| 事件顺序 | 正序 / 倒序 | **倒序**（最新在最上），符合外卖类 App 的心智；最新一条加粗 |
| 订单查询鉴权 | 与后台同权限 / 凭订单号匿名 | **匿名**。顾客没有账号；手机号脱敏后，泄漏面仅剩「楼栋+门牌」，与外卖平台取餐码同一级别 |
| 取消态展示 | 仍显示 4 节点 / 隐藏进度条 | **隐藏进度条**，顶部状态文案改为「订单已取消」。已完成/已取消是互斥终态，继续画进度条会造成误解 |
| 轮询容错 | 失败弹 Toast / 静默 | **静默忽略**，下一次轮询再试。网络抖动时弹窗会打断用户，而跟踪页本身不是强交互页面 |

## 4. 状态映射

| 订单状态 | 顶部文案 | 进度节点 | 轮询 |
|---|---|---|---|
| `pending` | 等待商家接单 | 已提交 ✓ / **已接单**（当前） / 制作中 / 已完成 | 继续 |
| `accepted` | 商家已接单，正在制作 | 已提交 ✓ / 已接单 ✓ / **制作中**（当前） / 已完成 | 继续 |
| `done` | 订单已完成 | 全部打勾 | 停止 |
| `canceled` | 订单已取消 | 隐藏进度条，时间轴保留 | 停止 |

## 5. 验证

| 用例 | 结果 |
|---|---|
| 下单后响应含 `events` | 1 条 `pending` |
| 匿名 `GET /api/orders/:id` | 200，`phone=136****5678`，`events=1` |
| 后台推 `accepted` | 200，事件链变为 `pending → accepted` |
| 再次匿名查询 | `status=accepted`，`events=2` |
| 跟踪页渲染（headless 截图） | 顶部「商家已接单，正在制作」；进度条第 3 节点高亮；时间轴 14:31 接单 / 14:30 下单 |
| 虚构内容清理 | 骑手卡片、「预计 12:35 送达」、写死时间轴均已移除 |

## 6. 没做的

- 轮询间隔固定 5 秒，未做「页面隐藏时暂停」（`visibilitychange`），后台标签页仍会每 5 秒请求一次；
- 订单号是「时间戳 + 4 位随机」，理论可枚举；演示场景可接受，生产应改为足够熵的随机串或加签名；
- 没有状态回滚：`done` 之后仍可被 `PUT` 改成 `canceled`，后续应加状态机白名单（当前只挡了改回 `pending`）。
