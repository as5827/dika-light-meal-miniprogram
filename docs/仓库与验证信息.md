## 复现要点

- 根目录**没有** `package.json`，不需要 `npm install`，`node server/server.js` 直接跑；
- 小程序端目录 `miniprogram/` 另有 `package.json`，只装类型检查用的两个开发依赖；
- 后台默认账号 `admin` / `dika2026`，可用环境变量 `ADMIN_USER` / `ADMIN_PASSWORD` 覆盖；
- 数据落在 `data/menu.json`，订单落在 `data/orders.json`（运行时生成，不进仓库）；
- 日志在 `logs/app.log`（JSON Lines，5MB 滚动）。
